## HOWTO

- run `./install.sh` to

  - symlink gemini.sh -> ~/bin/gemini
  - symlink system.md -> ~/.gemini/

- run `./build.sh` to build the `gemini` container image

- run `export GOOGLE_CLOUD_PROJECT=<your project>`

- run `gemini` from any directory you want to work with
